# Portfólio — Emmily Maciel

Site estático do portfólio, publicado em https://emmilymaciell.github.io.

`index.html` é a versão **pública** do dashboard de portfólio gerado pelo Ambient OS a partir de dados medidos dos projetos; sai sem caminhos locais, remotos privados, links internos, Drive ou Notion (verificação automática a cada geração). Projetos não publicáveis aparecem só como contagem.

Código dos projetos: ver os repositórios públicos do perfil [@Emmilymaciell](https://github.com/Emmilymaciell).
